# project-7-hospital-analysis
Healthcare data analysis with Python, SQL, and Tableau

Analysis of 1,753 hospital visits using Python (pandas, scipy), SQLite, and Tableau Public.

**Interactive Dashboards:** [View on Tableau Public](https://public.tableau.com/app/profile/marcello.velame/viz/Book2_project_7/StaysandReadmission)

## Key Findings
- Average length of stay varies by department, from 1.7 days (Emergency) to 6.7 days (Oncology). The difference is statistically significant (ANOVA, p < .001).
- Average length of stay rises with every age group from 10-19 through 80-89.
- Overall 30-day readmission rate is 12.78%. [add your department finding]
- Smoking status showed no significant association with readmission (chi-square, p = .207).

## Tools
Python, pandas, SQLite, scipy, Matplotlib/Seaborn, Tableau Public

## Data Note
The dataset in this project is synthetic and was generated for portfolio practice. It does not contain any real patient or protected health information (PHI).
